# PIURISE-Local-Viewer
Unofficial local score viewer for PUMP IT UP RISE

本アプリケーションは非公式で製作された、PUMP IT UP RISE用のローカルスコアビューワです。
すべてChatGPTによるバイブコーディングで生成されています。

原則としてゲーム本体やセーブデータの書き込み・改変・改竄を行わず、またアプリケーション単体の通信も行いません。

- 日本語/英語/韓国語 のローカライズを収録
- WARM UP/ARCADEの譜面毎のスコア一覧、WORLDMAXの詳細、統計情報等を表示できます
- 自己記録を細かくフィルタリングして分析することができます


ダウンロードはReleases欄から。必ずzipを展開した上、exeから起動してください。

記録を取得するには、アプリ内の「更新」またはF5を押してください。

本アプリケーションは26.09.14版までに対応しています。
